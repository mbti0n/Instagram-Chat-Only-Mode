# Instagram Chat-Only Mode
A userscript to restrict the Instagram desktop interface to only show Direct messages

[![Stars](https://img.shields.io/github/stars/mbti0n/Instagram-Chat-Only-Mode?style=for-the-badge)](https://github.com/mbti0n/Instagram-Chat-Only-Mode/stargazers) [![Install on Greasy Fork](https://img.shields.io/badge/Install-on%20Greasy%20Fork-6b00ff?style=for-the-badge&logo=greasyfork)](https://greasyfork.org/en/scripts/589961-instagram-chat-only-mode)

## What does it do?
(screenshots coming soon)
- Hide all sidebar buttons except the Hamburger/More button
- Force redirect to the Direct page, while keeping the ability to watch reels and view profiles from DMs.
