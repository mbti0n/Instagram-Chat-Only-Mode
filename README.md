# Instagram-Chat-Only-Mode
A userscript to restrict the Instagram desktop interface to only show Direct messages

## What does it do?
(screenshots coming soon)
- Hide all sidebar buttons except the Hamburger/More button
- Force redirect to the Direct page, while keeping the ability to watch reels and view profiles from DMs.
